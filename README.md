# e-plantShopping

## Project Overview

**e-plantShopping** is a React-based online plant shopping application. The project demonstrates how to build a modern front-end shopping experience using React components, state management, routing, and a clean user interface.

The application allows users to browse plant products, view product details, add items to a shopping cart, update quantities, and review selected products before checkout.

## Features

- Plant product listing
- Shopping cart functionality
- Add and remove products from the cart
- Update item quantities
- Reusable React components
- Responsive user interface
- Built with Vite and React

## Technologies Used

- React
- JavaScript
- Vite
- HTML
- CSS
